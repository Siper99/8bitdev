# 8.BIT.BLOG

A nostalgic gaming blog website with a retro 8-bit aesthetic.

## Pages

- **Home** (`index.html`) — Blog posts, sidebar with categories & tags, gaming hints, and upcoming events
- **About** (`about.html`) — Information about the blog
- **Contact** (`contact.html`) — Contact form/page

## Features

- Blog post cards with NES gamepad styling
- Sidebar with categories and tag cloud
- Gaming hints & tips section
- Upcoming events timeline
- Responsive navigation and footer

## Tech Stack

- HTML5
- CSS3 (`assets/styles.css`)
- JavaScript (`assets/script.js`)

## Topics Covered

Retro Gaming · Hardware Reviews · Gaming News · Indie Games · Tutorials · Game Reviews
